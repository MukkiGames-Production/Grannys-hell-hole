Rules and Regulations:
- Use camelCase for file names
- Use PascalCase for scene files
- Currently using place over assets, but may change in the future
- Folder structure:
  - Assets
	- Scenes
	- Scripts
	  - Network
	  - Player
	  - Interactables
	- Animations
	- Sprites
	- Audio
  - UI
	- MainMenu
  - Scenes
- branching Structure for the future:
  - main
  - development
	- feature-branch-1
	- feature-branch-2
  - feature branches should annotated as netowork, player, or interactables for easy identification
  - Mukki should handle the merge conflicts and merging of feature branches into development
  - if not mukki use GitKraken to see the changes and merge conflicts and resolve them
